# NovaMente — estudos de identidade visual

Três conceitos exploratórios de símbolo para o NovaMente. Todos são **SVGs vetoriais editáveis**, pensados para a paleta violeta `#8B5CF6` → ciano `#22D3EE` sobre grafite `#0B0B12`.

**Abra `index.html` no navegador** para comparar os três lado a lado.

## Conceitos

### 1. N de páginas (`conceito-1-n-pagina.svg`)

O N é formado por hastes que lembram uma página aberta, com um canto dobrado. É a direção mais sóbria e corporativa: fala de documentação, estrutura e clareza. Escala muito bem e é fácil de reproduzir em qualquer material.

- **Ponto forte:** legibilidade e simplicidade.
- **Risco:** pode ficar genérico sem um detalhe proprietário no refinamento.

### 2. N constelação (`conceito-2-n-constelacao.svg`)

O N é desenhado como uma constelação de nós conectados, com uma estrela mais brilhante no topo. Traduz o grafo/RAG e o “nova” do nome: uma nova estrela no conhecimento.

- **Ponto forte:** distintiva, memorável e tecnológica sem perder a legibilidade.
- **Risco:** se exagerar no brilho, pode soar como uma marca de IA genérica.

### 3. Página + faísca (`conceito-3-pagina-faisca.svg`)

Uma página que se dobra em N e libera uma faísca. É a direção mais humana e pedagógica: representa o momento em que um documento difícil se transforma em entendimento.

- **Ponto forte:** narrativa clara para educação.
- **Risco:** é a mais complexa em tamanhos pequenos; precisa de uma versão simplificada para favicon.

## Direção escolhida

O **conceito 3 — página + faísca** foi escolhido para refinamento. O kit de teste completo está em [`conceito-3/`](conceito-3/), com símbolo principal, compacto, monocromáticos, lockups e ícone de app.

Decisão de cor: a faísca acompanha o gradiente violeta → ciano na versão principal e no compacto; no ícone de app ela fica branca para contraste.
